# 이력서별 예시와 알려진 사실

- 작성일: YYYY-MM-DD
- 기준 문서: v.X.Y
- 사용처: resume-reviewer (판단 기준점, 알려진 사실), resume-update (복제 기준 항목)

[review-criteria.md](../review-criteria.md)와 [style-guide.md](../style-guide.md)의 일반 규칙을 실제 이력서에 적용했을 때 걸린 사례를 적는다. 처음에는 비워 두고, 첫 리뷰 후 채워도 된다.

## 알려진 사실

리뷰하기 전에 확인한다. 이미 확인된 사실은 다시 묻지 않고, 지적 대신 대응 방안을 제안한다.

| 사실 | 확인일 | 리뷰에서 다루는 법 |
