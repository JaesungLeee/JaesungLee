# 이력서 프로필

resume-reviewer, resume-update가 시작할 때 읽는 개인 설정이다. 이 폴더(`private.example/`)를 `docs/resume/private/`로 복사한 뒤 값을 채운다. `private/`는 git에 올라가지 않는다.

| 키 | 값 |
|---|---|
| 파일명 접두어 | `{이름}_경력기술서_v.` |
| 파일명 형식 | `{이름}_경력기술서_v.{major}.{patch}` (v 뒤에 점이 있다) |
| Drive 폴더 이름 | `{폴더 이름}` |
| Drive 폴더 id | `{폴더 id}` |
| 버전 관리 제외 파일 | `{예: 경력기술서 샘플}` |

## 버전 목록 (YYYY-MM-DD 기준)

- `{이름}_경력기술서_v.X.Y`: 최신, YYYY-MM-DD 수정

문서 링크와 변경 이력은 [CHANGELOG.md](CHANGELOG.md)에 있다.
