# 경력기술서 변경 이력

최신 버전이 맨 위에 온다. 버전 규칙은 [versioning.md](../versioning.md)에 있다.

항목 형식:

```markdown
## v.X.Y (YYYY-MM-DD)
- 구분: major / patch
- 기준 문서: v.X.Y
- 변경 내용
  - 섹션 > 항목: 무엇을 바꿨는지
- 반영한 리뷰: reviews/파일명.md #1, #3 (없으면 생략)
- 문서: [{이름}_경력기술서_v.X.Y](Google Docs 링크)
```

공고 맞춤본은 버전 이력과 섞지 않고 파일 맨 아래 "공고 맞춤본" 섹션에 최신순으로 쓴다.

```markdown
### 회사명 (YYYY-MM-DD)
- 기준 문서: v.X.Y
- 공고: 포지션명 (URL)
- 변경 내용
  - 섹션 > 항목: 무엇을 바꿨는지
- 반영한 리뷰: reviews/파일명.md #1, #3 (없으면 생략)
- 문서: [{이름}_경력기술서_회사명](Google Docs 링크)
```
